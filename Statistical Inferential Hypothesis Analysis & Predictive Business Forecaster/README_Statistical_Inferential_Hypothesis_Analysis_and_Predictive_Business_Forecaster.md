# Statistical Inferential Hypothesis Analysis & Predictive Business Forecaster

**Author:** Mohtasim Ahmed Awan
**Internship:** Progree Internship — Data Analytics Domain

## Overview
This project applies statistical hypothesis testing and predictive forecasting techniques to retail sales data, combining inferential statistics with a time-series forecasting model to support data-driven business decisions.

## Objectives
- Assess data quality and prepare date/time features
- Explore sales data descriptively and visually
- Analyze correlations between business variables
- Test hypotheses relevant to business questions using appropriate statistical tests
- Build a regression model to predict sales
- Forecast future sales using a SARIMA time-series model with prediction intervals

## Pipeline Steps
1. Load the dataset
2. Initial dataset inspection
3. Data quality assessment
4. Date conversion and time feature extraction
5. Descriptive business analysis
6. Exploratory data visualization
7. Correlation analysis
8. Statistical hypothesis testing:
   - Two-group hypothesis test — Discount vs. No Discount
   - ANOVA — Customer profitability across segments
   - Chi-Square test — Customer segment vs. region
9. Multivariate regression for sales prediction
10. SARIMA model selection
11. Forecasting with 95% prediction interval
12. Statistical test summary
13. Export of results for Power BI
14. Final conclusions

## Tools & Libraries
- Python
- pandas, numpy
- matplotlib, seaborn
- scipy, statsmodels
- scikit-learn

## Output
A set of statistically validated business insights (hypothesis test results, ANOVA, Chi-Square) alongside a sales forecast with prediction intervals, exported for Power BI reporting.
